﻿# Python + FastAPI 学习项目

一个「边写接口边学 Python」的演示项目：用中文注释把 Python 核心知识点串起来，
每个知识点都配有可运行的示例，方便对照学习。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `main.py` | FastAPI 接口代码，每个接口融合一个 Python 知识点；入口挂了登录门禁中间件 |
| `auth.py` | 登录 / 会话 / 访问控制（PBKDF2 密码哈希 + HMAC 签名 Cookie + 中间件，只用标准库） |
| `python_basics.py` | Python 基础语法速查（可直接运行） |
| `python_advanced.py` | Python 进阶知识点速查（可直接运行） |
| `run.py` | PyCharm 调试入口（直接用 Debug 按钮启动服务） |
| `douyin_downloader.py` | 抖音视频下载网页工具（页面在 `/douyin-download`） |
| `launcher.py` | EXE 启动入口：启动服务并自动打开浏览器 |
| `ai_chart.py` | AI 数据图表分析（页面在 `/ai-chart`，模型 Key 见下方「模型配置」） |
| `buy_helper.py` | 购物比价助手（页面在 `/buy-helper`；没配 Key 也能直接跳平台搜索） |
| `bill_analysis.py` | 账单分析（上传月度账单 Excel/CSV 到 `/bill-analysis`，DeepSeek 分类汇总消费并给省钱建议） |
| `translator.py` | 翻译助手（页面在 `/translator`：输入中文 -> 免费接口返回英文，并转换小写/大写/驼峰命名格式） |
| `ocr.py` | OCR图片识别（页面在 `/ocr`：粘贴截图或上传图片 -> 免费云端接口 OCR.space 识别成文字，无需本地模型，部署体积小） |
| `judgement_trainer.py` | 判断力教练（页面在 `/judgement-trainer`：写下正在犹豫的真事，先写上打算和几成把握，大模型把事实 / 猜测 / 你其实在赌什么 / 漏掉的变量摊开，到期回访对答案；没配 Key 走本地规则粗拆，记录存浏览器） |
| `sdd_decomposer.py` | SDD 需求拆解器（页面在 `/sdd-decomposer`：把模糊想法按七段式逼成结构化规格，实时编译成可丢给 agent 的提示词，纯浏览器计算） |
| `socratic.py` | 苏格拉底提问（页面在 `/socratic`：一个只会提问、不给答案的引导者 —— 写下你想理清的事，它按「澄清问题 → 已有信息 → 换个视角 → 推导结论」四步走，一次只问一个问题；回复**逐字流出来**（SSE），走完最后用你自己说过的话帮你收个尾。进度由服务端定，会话存 SQLite，右侧历史能回看、换台设备接着聊） |
| `writing_ideas.py` | 写作选题（页面在 `/writing-ideas`：给一点线索或什么都不给，大模型一次出一批选题，挑中一个拆成启动包（标题 / 结构 / 证据 / 反驳），没配 Key 走内置配方，数据存浏览器） |
| `predict_diary.py` | 贝叶斯日记（页面在 `/predict-diary`：写下你拿不准的一件事和现在几成把握，以后来一条新消息就更新一次；数字全在 Python 里用贝叶斯算，大模型只负责听懂人话；记录存浏览器） |
| `langchain_test.py` | LangChain 测试台（页面在 `/langchain-test`：四个最小可跑的例子 —— 大模型调用 / 提示词模板 + 链 / 工具调用 / 上下文，每行都写了注释。页面上显示的源码是服务端用 `inspect.getsource` 现读的，所以永远和真正在跑的那份一致；每次运行落一条 SQLite 记录，右侧历史能回看、能删，页面还认 `?r=<记录 id>` 深链。顺带把 5 个接口和 curl 调用方式直接印在页面上） |
| `study_assistant.py` | 学习模型助手（页面在 `/study-assistant`：写下想学什么，可选补一句「现在会什么 / 卡在哪」，大模型用第一性原理 / 金字塔原理 / 贝叶斯定理各出一棵可折叠的思维导图，再给 3~5 步能马上动手的清单；拆解存 SQLite，右侧历史点一条就能回看，勾掉做完的步骤自动保存） |
| `rumination.py` | 内耗拆解（页面在 `/rumination`：工作上的糟心事反复想时用，先 90 秒降温，再由大模型把一团拆成一条条、分成「我能动的 / 动不了的」，最后落成一件今天就能做的事；没配 Key 走本地规则，记录存浏览器） |
| `opc_news.py` | OPC 资讯（页面在 `/opc`：给做「一人公司 / 独立开发」的人用，按主题搜 GitHub 上的相关项目，star / 活跃度由 Python 算，再让大模型用中文说清每个是什么、有什么用、适合谁；`GITHUB_TOKEN` 和模型 Key 都从环境变量取，页面上不用填。顶上分「OPC 项目」「OPC 资料」两个 tab，后者是内置资料架，纯静态不落库） |
| `reading_practice.py` | 读书落地（页面在 `/reading-practice`：输入书名 + 作者，大模型不给读书笔记，只给今天能照着做的动作——什么场合用 / 三步怎么做 / 怎么算做到 / 容易在哪变形 / 7 天后问自己什么；拆出来的卡可勾步骤、到期回访，只存浏览器） |
| `kolb.py` | 库博学习圈（页面在 `/kolb`：把一件真实发生过的事走完具体经验 → 反思观察 → 抽象概念化 → 主动实验四段，AI 每段只追问一个问题；走完给一张经验卡，第四段的「下次实验」能一键送进判断力教练，到期对完答案回显「已验证 / 被推翻」；每个圈存 SQLite） |
| `five_why.py` | 5Why 分析法（页面在 `/five-why`：输入一个问题，AI 一层层问「为什么」并给出不同角度的候选答案；每答一层做顺读 / 逆读检查并判断「该停还是该继续」，但只在跳步 / 链子跑偏 / 答案不可操作时才在对话里点出来，正常层保持沉默；落到具体机制才让做根因验证，再配对策（谁 / 何时 / 怎么做 / 怎么验）；报告由 Python 拼，每个会话存 SQLite） |
| ``ask_hub.py`` | 5Why 分析 + 苏格拉底提问的**合并页**（页面在 ``/ask-hub``）：顶上一条 tab 栏，把两个只会提问的工具放在一页里切换，省得来回跑工具箱。这一页本身只是一层壳 —— 两个工具各自的页面（``/five-why`` / ``/socratic``）和接口一个字没动，被嵌进 iframe 时用 ``?embed=1`` 藏掉自己的顶栏、不再铺一层粒子背景；切 tab 只是显示 / 隐藏，不重新加载，聊到一半切走再切回来还在原地。两个工具的数据仍然分开存在 ``history`` 表里（``five_why`` / ``socratic``），深链 ``/ask-hub?tab=why|soc&r=<记录 id>`` |
| `script_library.py` | 脚本库（页面在 `/script-library`：把散在本机的小脚本登记成卡片 —— 干什么 / 怎么跑 / 依赖什么 / 放在哪，能标「用过了」，空库时给八条上手灵感。解决的是「想不起来」，不是「没有脚本」，记录存 SQLite） |
| `goal_split.py` | 目标拆解器（页面在 `/goal-split`：不管你想做什么，先把你从「我想……」逼到能验收的一句话 —— 量什么 / 现在是几 / 做到几 / 什么时候截止。然后五步往下：为什么是它（以及愿意放弃什么）→ 倒推 1~6 站里程碑（每站要有验收标准和日期）→ 只把第一站拆成本周动作（每条要带预估分钟、可观察产出、哪天做）→ 体检 + 失败预案。AI 每一步只问一个问题、绝不替你写答案，它还能把你刚答过的话整理成字段填进表单（你确认过才存）。体检那六条 —— 可验证性 / 时间账 / 粒度 / 顺序 / 可控性 / 失败预案 —— 全部是 Python 按规则算出来的，模型只负责讲人话；存下来之后进「监督」页：今天该做的排最前，勾一条动一次进度，里程碑到期回访，每周登记一次真实投入和漏掉几件，这些偏离数据会回填进下一次体检的时间账。每条目标存 SQLite，页面认 `?r=<记录 id>` 深链） |
| `storage.py` | SQLite 存储层（全站唯一的落盘入口：库文件在 `data/app.db`，WAL 模式，按登录名隔离；`add_record` / `list_records` 给所有工具存历史记录用） |
| `db_viewer.py` | 数据浏览（页面在 `/db`：SQLite 的只读查看器 —— 左边点表翻数据、点表头排序、搜关键词，右边随手写 SQL，结果能一键画成柱状图 / 折线图 / 饼图，也能导 CSV。连接用 `mode=ro` 打开，且只放行 `select` / `with` / `explain`，写操作进不来） |
| `site_collect.py` | 网站收集（页面在 `/site-collect`：刷到有用的网址就丢进来 —— 网址 / 名称 / 分类 / 状态 / 标签 / 备注，能改能删能搜。它要解决的不是「存不下」，而是「存了却不知道当初为什么存」—— 所以「收集理由」必填，空着不让存；「AI 看看值不值得收」会先由服务端真去抓这个页面（标题 / 描述 / 正文前若干字，带 SSRF 防护、只放行公网 http/https），再让模型评一句：值得留 / 看情况 / 别收了，连同「值在哪、什么场合用、可能变成再也不打开的坑、判断依据」一起给出，抽象空话被 prompt 明令禁止；分析结果连依据一起存进这条记录，下次打开还在。记录存 SQLite，页面认 `?r=<记录 id>` 深链） |
| `overview.py` | 记录总览（页面在 `/overview`：跨工具只读汇总 —— 把判断力教练 / 5Why / 苏格拉底 / 学习模型助手 / 读书落地 / AI 图表存进 `history` 表的记录汇到一页，能按天 / 按周 / 按月看，按工具筛、搜关键词、只看没收尾的，列表每页 10 条，展开能看见当时记了什么；每条旁边有「直接打开这一条」，点了会跳到那个工具并自动展开那一条；不新增记录入口，写数据仍是各工具自己的事） |
| `Dockerfile` / `docker-compose.yml` | 上云用的镜像定义与编排（`data/` 挂载成卷，账号与模型 Key 走 `.env`） |
| `deploy/` | 部署脚本与文档：一条命令发布到自己的云服务器，以及服务器上的一次性准备步骤 |
| `templates/` 与 `static/` | 各工具页面模板与本地静态资源（含登录页 `templates/login.html`、会话兜底 `static/auth-guard.js`） |
| `requirements.txt` | 项目依赖（fastapi + uvicorn + requests + yt-dlp + playwright + openpyxl） |

## 怎么运行

先激活虚拟环境并安装依赖：

```bash
# Windows
.venv\Scripts\activate
pip install -r requirements.txt

# macOS / Linux
source .venv/bin/activate
pip install -r requirements.txt
```

运行 Python 学习脚本（推荐先跑这两个）：

```bash
python python_basics.py
python python_advanced.py
```

启动服务（两种方式任选其一）：

uvicorn main:app --reload        # 学习接口 + 抖音下载器都在这个应用里
# 或只启动抖音下载器（同样可访问 http://127.0.0.1:8000/douyin-download）
python douyin_downloader.py
python video_downloader.py
```

然后在浏览器打开（**首次会先跳到登录页，创建账号后才能进**）：

- `http://127.0.0.1:8000/hello/小明` 路径参数

- `http://127.0.0.1:8000/ai-chart` **AI 数据图表**：输入主题，大模型自动整理数据并生成图表，支持导出 Excel

- `http://127.0.0.1:8000/five-why` **5Why 分析法**（**已并入 `/ask-hub`，这里仍可单独访问**）：输入一个问题，AI 像聊天一样一层层问你「为什么」，每层给几个不同角度的答案供你挑或改；顺读 / 逆读自动检查（没问题就不吭声，只在跳步或链子跑偏时提示），拦住「某人不小心」「沟通不畅」这种没法动手的答案，最后出一份根因 + 对策报告，可导出 Markdown
- `http://127.0.0.1:8000/kolb` **库博学习圈**：挑一件真实发生过的事，走完「具体经验 → 反思观察 → 抽象概念化 → 主动实验」四段：AI 每段只追问一个问题，把你逼到具体；走完给一张经验卡（一句话原则 + 边界 + 下次实验），能一键送进判断力教练去对答案，到期回显「已验证 / 被推翻」

## 登录与访问控制

打开 `http://127.0.0.1:8000/` 会先跳到 `/login`：**第一次使用先创建账号**（用户名 + 密码），之后每次进来都要登录。
没登录的人既看不到页面，也调不到任何接口。

怎么实现（都在 `auth.py`）：

- **密码**：PBKDF2-HMAC-SHA256，20 万轮 + 每条账号独立随机盐，存 `data/auth.json`，文件里没有明文；
- **会话**：HMAC-SHA256 签名的令牌放在 HttpOnly Cookie（`tb_session`）里，服务端不存 session 表；
  签名密钥首次启动自动生成到 `data/secret.key`，所以重启服务不会把已登录的人踢下线；
- **门禁**：`LoginGate` 中间件在所有路由之前执行 —— 页面请求没登录就 303 跳 `/login?next=原地址`，
  接口请求没登录就返回 401 JSON；白名单只有 `/login`、`/api/auth/*` 和 `/static/`；
- **兜底**：`static/auth-guard.js` 挂在每个页面里，任何请求拿到 401 会自动回到登录页（并记住原地址）。

另外三条防护：

- 连续输错 6 次密码，同一 IP 锁 5 分钟（`429`）；
- 跨站发来的写请求（`Origin` / `Sec-Fetch-Site` 不匹配）直接 `403`，防 CSRF；
- 改密码会让所有旧会话立即失效（令牌里带了密码指纹），改完当前设备自动续期。

数据文件都在 `data/`（已在 `.gitignore` 里）：`auth.json` 账号、`secret.key` 签名密钥。
忘了密码就删掉 `data/auth.json`，刷新页面会回到「创建账号」。

### 部署到 Vercel 这类只读环境

云函数的文件系统除 `/tmp` 外是只读的，`data/` 写不进去（创建账号会 500）。
所以 `auth.py` 支持「用环境变量当账号」，配了环境变量就不再读写任何文件：

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `TB_USERNAME` | 是 | 登录名 |
| `TB_PASSWORD` | 是 | 登录密码（首尾空格会被忽略） |
| `TB_SECRET` | 否 | 会话签名密钥，随便一串长随机字符；不配就从账号凭据派生 |
| `TB_PASSWORD_DIGEST` / `TB_PASSWORD_SALT` / `TB_PASSWORD_ROUNDS` | 否 | 只想放摘要、不想放明文时用，可替代 `TB_PASSWORD` |

配好之后：登录页自动变成「登录」而不是「创建账号」，`/api/auth/setup` 和改密码接口会明确拒绝
（而不是 500）。改了变量要**重新部署**才生效；一个变量都不配时，退回本机 `data/auth.json` 那套，本地开发流程不变。

## 浅色 / 深色主题

首页右上角有个太阳 / 月亮按钮：默认浅色（太阳），点一下整站变深色（月亮）。

- 状态存在浏览器 `localStorage['tb_theme']`，按域名共享，所以**在首页切一次，所有工具页都跟着变**，不用每个工具再切一遍；
- 颜色全部收在 `static/theme.css` 的 `--tb-*` 变量里（浅色一组，`[data-theme="dark"]` 一组），`static/theme.js` 负责切换、画按钮和多标签页同步；
- 每个页面 `<head>` 里先跑一段内联脚本把 `data-theme` 写上，所以不会出现「先白一下再变黑」的闪烁；
- 图表（ECharts）的颜色改成 `TBc('--tb-muted')` 这种写法，渲染时取当前主题的值，切主题后重新出图就是新配色；
- 判断力小工具和 SDD 拆解器自带的主题按钮也写到同一个 key 上，在哪切都是整站生效。

## 动态背景（粒子星链）

每个页面都挂着一层动态粒子背景，切到哪个工具都在，不用单独配。

- `static/particles.js` 生成一个铺满视口的 canvas（`#tb-fx`），画在内容背后（`z-index:-1`，`pointer-events:none`，不挡点击）；
- 四层叠出效果：星云光斑（缓慢游走的大色块）→ 星链连线（按距离连，鼠标靠近会推开粒子并点亮连线）→ 微粒光晕 → 每十几秒一颗流星；
- 颜色跟着浅色 / 深色主题走，深色模式用更亮的颜色加 `lighter` 叠加，浅色模式用加深后的同色系；
- 为了让它露出来，`static/theme.css` 里把 `body` 底色压成了透明，页面底色与氛围光斑改由 `html` 提供（`--tb-page-glow-1/2/3`）；
- 尊重 `prefers-reduced-motion`（只静态画一帧）、标签页切到后台自动暂停、粒子数按视口面积自适应、DPR 上限 2。

## 贝叶斯日记

| 3 | 大模型把那团东西拆成一条条，标成「发生的事 / 我猜的 / 我给自己的评价」 | 内耗的燃料是抽象，把它压回具体就烧不起来了 |
| 4 | 一条条分：我能动 / 一半能动 / 动不了 | 大部分内耗，是把「动不了的」当成「动得了的」在反复想 |
| 5 | 收口：一件今天就能做的事 + 一句拉开距离的话 + 一句「如果是最好的朋友」+ 担忧盒 | 只给一件，给多了等于没给 |

说明：

- 大模型只做三件语言活：拆句、判断这条能不能推动、生成收口那几句话。流程、步数、统计都在前后端控制，跟贝叶斯日记一个思路；
- 没配 `DEEPSEEK_API_KEY` 也能走完全流程，只是拆得粗一些（本地关键词规则），页面上会标出来这次是哪种；
- 担忧盒里的条目放一天后会问你「它真发生了吗」，攒够几条就能在首页看到「你担心的事，真正发生了多少」——这个数字比任何安慰都管用；
- 记录只存浏览器 localStorage（`rm_sessions_v1` / `rm_box_v1`），服务端不存、不写日志。唯一离开本机的是你主动点「AI 拆」时发出去的那段文字；
- 它是一个自助工具，不是治疗。如果这种感觉持续两周以上，或者冒出伤害自己的念头，打 **12356**（全国心理援助热线，24 小时，免费）。

## 读书落地

打开 `http://127.0.0.1:8000/reading-practice`。填书名 + 作者（可以再补一句你想用它解决什么），点「拆成能做的事」。

出来的是 2-4 张实践卡，每张卡就五样东西：

| 卡片上的字段 | 是什么 |
| --- | --- |
| 什么场合用 | 写清时间、人物、触发条件（「周三下午领导临时插活，你手上已经排满」），不是「工作中」 |
| 三步 | 每步以动词开头，带时间或数量，能真做完 |
| 算做到 | 别人能看见的结果，不是「我记住了」 |
| 容易变形 | 这件事最容易走样的地方（「变成列 20 条的清单，一条都做不完」） |
| 7 天后问 | 到期回访要回答的那一句 |

说明：

- 这个工具最怕的是模型编书：编书里没有的实验、章节、人名、年份。所以 prompt 里明令禁止编细节，不确定就写「我没把握这本书的具体内容」，宁可笼统；页面上会把模型自己写的这句提示顶到最上面；
- 你写的诉求和这本书关系不大时，它会直说，而不是硬凑；纯小说 / 诗歌这类给不了动作的书，它会改成给「怎么把它的视角用在自己身上」；
- 拆完点「就做这张」会进「我在做」：三步可以勾选，7 天后弹出那句「问自己」，回答「做到了 / 没做到」后进「已收尾」；
- 没配 `DEEPSEEK_API_KEY` 时不编内容，改成给你一份自己拆的六问模板（抄原文、写场合、第一步、怎么算做到、哪里会变形、7 天后问什么）；
- 实践卡只存浏览器 localStorage（`rd_plans_v1`），服务端不存、不写日志。

## 5Why 分析法 / 苏格拉底提问

**入口：`http://127.0.0.1:8000/ask-hub`** —— 这两个工具已经合成一页，顶上切 tab。
（`/five-why` 和 `/socratic` 仍然可以单独打开，老链接不会失效。）

下面说的是 5Why 那一半。**这一版是对话式的**：你只写一句话，剩下的问由 AI 来问。

为什么不做成表单：说不清根因的人，缺的从来不是输入框，是「下一层想不到」。所以这里由 AI 主导，每一轮干三件事：

上面那三件事只在**出问题的时候**才显示在对话里（跳步 / 逆读解释不了 / 答案是不可操作的表述）；一切正常就什么都不说，直接把下一个问题递上来 —— 每层都播报一遍「顺读成立、逆读能解释」，到第三四层就是复读机，人会习惯性跳过，真出问题那层也跟着被跳过。

| 它做什么 | 具体是 |
| --- | --- |
| 问下一层 + 给候选 | 每层给 2–3 个**不同角度**的候选答案（流程 / 系统与规则 / 信息传递 / 动作与工具 / 资源与排期）—— 点一个填进来、改一改也行、自己重写也行。想不出下一层时，这一步最值钱 |
| 顺读 + 逆读 | 把上一层读成「所以……」，看这一层能不能真的推出它（跳步 / 原地打转会被点出来）；再倒着推，看这一层能不能解释最上面那个现象。**没问题就不吭声** |
| 该停还是该继续 | 落到「能被直接改变的具体机制」（哪条规则缺了、哪个字段没校验、哪个阈值没设、哪个时间点没东西提醒）→ 直接转去根因验证（那句话本身就把这个节点讲清了）；还停在「某人不小心 / 沟通不畅 / 责任心不强 / 培训不到位 / 执行力差」，或者只写了个某人、某个部门的名字 → **这里会出声**，带着一句具体的追问让你继续 |

走完的五个阶段（页面上有进度条）：

1. **确认问题** —— 只写一句你要追的事就行（不填别的）；写成「因为……人手不够」这种原因也没关系，它会先把问题按回「发生了什么」
2. **一层层问** —— 上面那三件事循环
3. **根因验证** —— 「如果这条不存在，问题还会发生吗？」选「还会发生」就说明还没到底，带你继续往下追
4. **配对策** —— 四样都得写：做什么 / 负责人 / 完成时间 / 如何验证有效。「加强培训」「提高意识」这类会被当场打回，打回时输入的内容不丢
5. **收尾** —— 出一份能直接拿去开会的报告

细节：

- **只需要一个问题**：不用填时间 / 地点 / 数量这些附加信息，写一句你要追的那件事就能开始；
- **同层可以拆并列原因**：点「还有别的原因」，这一层先记下，接着问同一层的另一个角度（树状，不是硬凑单链）；
- **追歪了可以撤**：点「撤销上一层」把最后一层去掉重答，链会退回上一层继续问；
- **报告由 Python 拼，不让模型重写**：交付物和你亲口说过的必须一字不差。报告含 问题 / 因果链 / 根因（带验证结论）/ 对策表 / 待办清单，可复制成 Markdown、下载 `.md`、直接打印（A4 样式已调好）；
- 5 层是经验值不是硬规定，页面上一路标着；追到第 7 层还在描述，它会提醒「也许该换一条链，或者问题描述得太大」；
- 判定走「本地规则 + 模型复核」两层：模型失败一律按「继续」走，宁可多问一层，也不会因为一次网络抖动把链掉断；
- 键盘：Enter 直接发、Shift+Enter 换行、Ctrl/⌘+Enter 在任何位置提交；
- 每次分析落 SQLite（`tool='five_why'`），右侧列表点一条就能接着聊，换台设备回来还在；
- 旧版（表单式）的记录靠 `payload.v=2` 区分，**不显示也不删除**，数据还躺在库里（`/db` 能看到）；
- 没配 `DEEPSEEK_API_KEY` 时这个工具用不了（它全靠对话），页面会直接写清楚。

## OPC 资讯

打开 `http://127.0.0.1:8000/opc`。页面分两个 tab，顶上切换。

### OPC 项目（默认）

给做「一人公司 / 独立开发」的人用：按主题搜 GitHub 上相关的项目，再让大模型用中文说清每个是干什么的。

| 步骤 | 做什么 |
| --- | --- |
| 1 | 点一个主题标签（一人公司 / 独立开发者 / AI SaaS 起步 / 资源清单…），或者自己敲关键词 |
| 2 | 挑「最低 star」档位，需要时开「只看活跃」（三个月内有提交） |
| 3 | 点「AI 解读这 12 个」，每个项目多出「是什么 / 有什么用 / 适合谁」三行，最上面还有一句「这批怎么看」 |

说明：

- star、fork、距今多少天没提交、活跃度分档（活跃 / 维护中 / 停更）、是否已归档，全是 Python 算的，不是模型猜的；
- 大模型只做语言活，提示词里明令禁止它补充没看到的细节——这类任务模型最爱编功能清单，而它能依据的只有作者自己写的那行描述；
- 关键词要英文：GitHub 搜的是英文描述，主题标签因此都是英文，中文的搜不出东西；
- 不配 `GITHUB_TOKEN` 也能用，但走未认证额度（搜索 10 次/分钟），被限流时页面会写清多少分钟后恢复；
- 同一个查询 10 分钟内不重复打 GitHub（服务端内存缓存）；AI 解读结果存浏览器 localStorage（`opc_ai_v1` / `opc_cfg_v1`），换个关键词回来还在。

### OPC 资料

一个内置的资料架，六组：收款与合规、部署与数据库、上线以后的零碎（登录 / 邮件 / 统计 / 报错）、AI 接口、发出去的地方、常读。每条给一句实话加官网链接。

- 分类和关键词是「同时满足」，卡在某一组里搜不到时页面会提示切回「全部」；
- 「复制链接」优先走剪贴板 API，线上是 http 拿不到它，会自动退回 `execCommand`；
- 「导出这批」把当前筛出来的导成 Markdown，用的是公共件 `static/export-md.js`；
- 换 tab 会记在地址上（切到资料是 `#ref`），刷新还停在那儿；两个 tab 的状态各自留着，来回切不会把搜索结果丢掉；
- 这页是**静态资料**，写在 `templates/opc.html` 里，不落库也不发请求。要改成「自己能往里存资料」才需要接 `storage.py`。

## 数据存储（`storage.py`）

全站唯一的落盘入口：所有工具的历史记录都写进同一个 SQLite 文件，库里到底存了什么，打开 `/db`「数据浏览」就能翻。

目前接上的是 **AI 数据图表分析**（`/ai-chart`）：每次成功生成的图表数据都写进 `history` 表，
右侧历史面板每次打开都从库里查（`GET /ai-chart/api/history`），点「清空」走 `DELETE`。

之后接上的是 **5Why 分析法**（`/five-why`）：每次分析就是 `history` 表一行（`tool='five_why'`，`payload.v=2`，整条因果链 + 对策 + 报告都在里面）；读写走 `GET|POST /five-why/api/sessions` 和 `GET|PATCH|DELETE /five-why/api/sessions/{id}`，追问走 `POST /five-why/api/sessions/{id}/reply`；列表不带 `msgs` 和 `report`（省流量），点开才取全量；`payload` 里没有 `v=2` 的旧记录直接跳过，不显示也不删。

- **库文件**：默认 `data/app.db`，可用环境变量 `TB_DB_PATH` 改（Docker 里指向挂载卷就行）；
- **连接**：每次操作开短连接，`journal_mode=WAL` + `busy_timeout=3000`，读不挡写、写不互相锁死；
- **两张表**：`history`（通用历史记录，所有工具共用）、`notes`（一张示例表，`add_note` / `list_notes` 留着当抄写模板）；
- **隔离**：每条记录都带 `user` 字段，按登录名分开，互相看不见；
- **兜底**：文件系统只读（Vercel 这类）时抛 `StorageUnavailable`，接口回一句人话，不会 500。

其他工具接入就两步：

```python
import storage

# 写：结果和查询条件一起存下来
storage.add_record(tool='ai-chart', user=request.state.user,
                   title=主题, payload={'prompt': 主题, 'option': 选项})

# 读：最近 10 条（payload 已经还原成 dict）
rows = storage.list_records(tool='ai-chart', user=request.state.user, limit=10)
```

放进 Docker 时记得把 `data/` 挂出来，否则容器一重建数据就没了：

```yaml
services:
  app:
    build: .
    volumes:
      - ./data:/app/data      # auth.json / secret.key / app.db 都在这里
    environment:
      - TB_DB_PATH=/app/data/app.db
```

## 数据浏览（`/db`）

SQLite 从「能用」到「看得见」的那一步：不用装任何数据库客户端，浏览器里就能把库里存了什么翻出来。

- **左侧表清单**：每张表的行数 / 列数一眼可见，点一下切过去；
- **表数据页**：列结构（字段名 + 类型 + 主键）摆在最上面，下面是一页数据 —— 点表头排序、输关键词搜索（只扫文本字段）、上一页 / 下一页、导出 CSV；
- **SQL 查询页**：随手写查询，结果先按表格展示，也可以切成图表 —— 选好横轴（分类字段）和纵轴（数值字段），柱状 / 折线 / 饼图随便挑；下面备了几句常用 SQL（按工具统计、按天统计等），点一下直接跑；
- **导出 CSV**：表数据和查询结果都能导，带 UTF-8 BOM，Excel 直接打开不乱码。

安全上做了三层，因为这个页面能把整库摊开给人看：

1. 连接用 `mode=ro` 打开，**写操作由 SQLite 自己拒掉**，不靠代码自觉；
2. SQL 只放行 `select` / `with` / `explain`，并且整句不许出现分号（禁多条语句）；
3. 表名、列名必须先能在 `sqlite_master` / `PRAGMA` 里查到，才允许拼进 SQL。

想试的话：在 SQL 页里跑一句 `DROP TABLE notes`，它会直接告诉你「这个页面是只读的」。

> 这是**全库视图**：不按登录名过滤，所有账号的记录都能看到。自用单账号没差别；真要多人共用，再给它加一层过滤。
